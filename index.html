// Why Scrappy

Two layers of stealth.
Zero compromises.

Most scrapers only solve one problem. Scrappy stacks CloakBrowser and Hysteria2 to defeat detection at both the browser and network level simultaneously.

🔒
C++ Level Fingerprint Patches

Not JS injection. CloakBrowser patches Chromium at the source level — canvas, WebGL, audio, TLS fingerprint. Detection sites see a real human browser.

⚡
Hysteria2 QUIC Transport

Your traffic travels via QUIC protocol masquerading as HTTP/3. ISPs and firewalls can't block it without taking down real websites.

🌍
3 Global Proxy Regions

US, EU, and Asia nodes. Route requests through the closest exit point. Residential-grade exit IPs. Available on paid plans as raw SOCKS5/HTTP credentials.

🔄
Drop-in Simple API

POST a URL, get back HTML. No Playwright setup, no binary downloads, no proxy config. Add structured data extraction and screenshots with one flag.

📦
Batch Scraping

Scrape up to 10 URLs in a single API call, processed concurrently. Each URL counts as one request. Perfect for bulk data pipelines.

🛡️
Passes Cloudflare Turnstile

Both non-interactive and managed Turnstile challenges. Also passes ShieldSquare, FingerprintJS, BrowserScan, and bot.incolumitas.com.
